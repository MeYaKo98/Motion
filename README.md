## 📖 Overview
A lightweight, high-performance robotics framework designed specifically for **embedded applications** and **microcontrollers**. The framework provides a unified hardware abstraction layer (HAL) for sensors, actuators, and communication protocols.

## 🚀 Key Features
* **Interface-Driven Design:** Decouples hardware implementation from logic using the IO base class.
* **Low Memory Footprint:** Optimized for ESP32, STM32, and Arduino.
* **PlatformIO Ready:** Native support for the PIO ecosystem and unit testing.

## 📂 Project Structure
* `include/` - Header-only interfaces and core definitions.
* `src/` - Implementation files.
* `docs/` - Doxygen configuration and assets.
